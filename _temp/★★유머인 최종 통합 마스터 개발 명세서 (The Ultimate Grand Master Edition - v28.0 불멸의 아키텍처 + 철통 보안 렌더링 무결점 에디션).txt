악성 쉘(Shell) 화이트리스트 필터: .php, .exe 등 해킹 파일이 위장하여 올라오지 못하도록 allowedTypes 명단(jpeg, png, mp4 등)으로 철저히 검사하여 위반 시 400 에러 반환.

5-1. 🖼️ 초거대 이미지 무손실 분할 & 진공 압착 렌더링 엔진 (WebP 한계 돌파)
WebP 물리적 한계 방어 (16,383px 룰): WebP의 최대 해상도 한계(16,383px)로 인해 하단이 잘려나가는 치명적 버그를 원천 차단하기 위해, 분할 기준점을 15,000px로 절대 설정한다.

스마트 분할 투트랙 (15,000px 기준):

15,000px 이하: 단 한 번의 칼질도 없이 원본 1장 그대로 WebP 자동 압축(다이어트) 후 업로드하여 서버 자원을 절약한다.

15,000px 초과 (초거대 이미지): Canvas 엔진을 가동하여 15,000px 단위로 큼직하게 썰어내어(50,000px 웹툰도 단 4장으로 분할) 무손실 WebP 압축을 진행한다.

가로 폭 팽창 방지 자물쇠 (Width Lock):

Canvas 분할을 거친 조각 이미지가 Flexbox 안에서 억지로 에디터 100%에 맞춰 늘어나 화질이 깨지는 것을 막기 위해, 생성 단계부터 width: 100% !important; max-width: min(100%, 원본픽셀px) !important; 인라인 자물쇠를 강제 부여한다.

이로써 타 플랫폼 스킨과 무관하게 단 1픽셀의 팽창도 없이 원본 가로 비율을 100% 완벽하게 유지한다.

틈새 0px 진공 압착 CSS (하얀 실선 영구 멸망):

조각난 이미지를 감싸는 문단(<p>) 태그를 display: flex !important; flex-direction: column !important; margin: 0 !important; padding: 0 !important; line-height: 0 !important; font-size: 0 !important; align-items: center !important; 속성으로 강제 진공 압착시켜 여백을 영구 차단한다.

각 조각 이미지 사이에 margin-bottom: -1px !important; 오버랩 코드를 강제 주입하여, 브라우저 서브픽셀 렌더링 오차로 발생하는 미세한 하얀 실선조차 0%의 확률로 원천 방어한다.

10. 🚨 자동 블라인드 투트랙 연동 시스템 (The Perfect Blind)
🛡️ 신고 & 비공감 임계값 완벽 분리 연동: 관리자가 설정한 report_blind_threshold (예: 10회)와 별도로 비공감 임계값 dislike_blind_threshold (예: 100회)를 독립적으로 운영하여 비공감 테러로부터 헤비 업로더 완벽 보호.

🛡️ 관리자 사면권(is_safe) 영구 방어막: 관리자가 한 번 복구한 글/댓글은 악플러가 100만 번 비공감을 눌러도 WHEN is_safe THEN false SQL 조건에 의해 절대 다시 블라인드 되지 않는 철벽 방어 시스템 구축.

🤫 화면 덜컹거림 0% 사일런트 통신: 무작정 revalidatePath를 날리지 않고, 클릭 시 DB만 조용히 업데이트하다가 임계점에 도달하는 찰나의 순간에만 조건부 새로고침을 발동시켜 CLS(화면 튕김) 완벽 제어.

👁️ 트루먼 쇼 (작성자 투시 특권): 블라인드 된 글이라도 본인과 관리자에게는 정상 노출시켜 스스로 수정/삭제할 기회 보장.

11. 🚀 투트랙 베스트 정렬 & 순수 SQL 무결점 엔진 (Race Condition 영구 방어)
🧠 투트랙 시간 아키텍처 (대형 커뮤니티 표준): 총 추천 수가 많은 과거 글의 상위권 독식을 막기 위해, 리스트 정렬의 기준을 '베스트 달성 시간(best_at, best100_at, best1000_at)'으로 삼아 최근에 승급한 글이 순차적으로 맨 위에 오르도록(ORDER BY best_at DESC) 실시간 끌어올림 로직을 적용한다. 화면에 보이는 날짜는 원본 작성 시간을 영구 보존.

🏆 투데이 / 100 / 1000 베스트 단계별 승급 엔진 상세 명세:

투데이 베스트: 10추천에 도달하는 찰나의 순간, 그림자 컬럼 best_at에 현재 서버 시간(NOW()) 기록.

백 베스트: 100추천에 도달하는 순간, best100_at에 진입 시간 기록 및 승급 정렬.

천 베스트: 1000추천 도달 시, best1000_at에 시간 주입 및 최종 승급 정렬 배치.

🛡️ 동시성 오류(Race Condition) 원천 차단: 트래픽 폭주 시 JS 단에서 추천 수를 읽고 체크하는 땜질 코드를 전면 폐기. 금융권 수준의 순수 SQL 단일 트랜잭션(Atomic Update)을 적용하여 동시 접속자 10만 명 폭주 상황에서도 꼬임 발생 불가.

⚡ 임계점 찰나 돌파 로직: 기존 DB의 빈칸(NULL)이나 썩은 데이터를 무시하고 오직 best_at = CASE WHEN COALESCE(likes, 0) = 9 THEN NOW() ELSE best_at END (백 베스트는 99, 천 베스트는 999) 이라는 가장 직관적인 조건식을 적용, 임계점을 돌파하는 유일한 찰나(Old-Value 평가)에만 실시간 타이머 스탬프(NOW())를 단 1번 강제 주입.
